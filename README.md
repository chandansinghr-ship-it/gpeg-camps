# 🎨 GPEG Camps Command Center

A premium, highly interactive full-stack sandbox portal built to coordinate, streamline, and optimize the Google GPEG Camps execution lifecycle.

✨ **Live Static Interactive Demo**: [https://chan8822.github.io/camps-portal/index.html](https://chan8822.github.io/camps-portal/index.html)

---

## 🌟 Features Overview

This application includes a fully functioning **client-side browser database simulator**, enabling E2E execution flow testing with zero dependencies:

*   **Dynamic Multi-Role RBAC Controls**: Instantly switch between **Admin, Organizer, Presenter, Area Manager (AM), PM (Program Manager), and Stakeholder** to view distinct layouts, portfolio scopes, and operation permissions.
*   **Interactive Kanban Pipeline**: Drag-and-drop nominations, kickoff new camps, schedule sessions, and assign lead presenters.
*   **Agency Discovery & CSAT Portal**: Real-time surveys to tailor slides (customized deck protocol) and collect post-camp CSAT / business impact metrics.
*   **Weekly Calendar & Double-Booking Conflict Alarm**: Visual schedule slot reservation with double-booking conflict detector.
*   **PM Technical Escalation Queue**: Ingest live client questions from presentation slides and author resolutions.
*   **Gmail Outbound Gateway Simulator**: Automatically draft and review rich HTML formatted emails for case lifecycle triggers.
*   **SLA Calendar Time Machine**: Advance dates to test SLA warnings and default-deck protocol downgrades.
*   **Team Collaboration Chatbot**: Real-time reactive team chat channel with automated AM assistant.

## 🚀 Staged E2E Lifecycle Test Workflow

1.  **Ingest Connect Nomination** (`Admin`): Nominate a new camp from the Connect Sandbox tab.
2.  **Schedule & Assign** (`Organizer`): Drag cards to Pre-Camp Prep, select presenter, schedule time, and dispatch automated kickoff emails.
3.  **Submit Client Discovery Form** (`AM / Client`): Fill discovery surveys in the Agency Portal to upgrade the default deck to **Customized Slide Deck Protocol**.
4.  **Live slide & Escalate question** (`Presenter`): Conduct the live workshop, run through the presentation console, and escalate questions to the PM queue.
5.  **Resolve Technical Ticket** (`PM`): Author resolutions inside the PM escalation queue, automatically drafting synced client notification emails.
6.  **Complete follow-up & CSAT** (`Organizer & AM`): Drag cards to Post-Camp SLA, send follow-up packages, and log final CSAT and ARR uplift metrics!
